# copicol

Chemins trop longs ? 
Vos fichiers méritent mieux qu'une erreur Windows.
Copiez vos dossiers depuis un NAS, un serveur ou un disque, même lorsque leurs chemins dépassent les limites de Windows.
Copicol raccourcit automatiquement les noms, conserve leur correspondance et permet de restaurer l'arborescence d'origine.

Sans installation
Reprise après interruption
Restauration réversible

## Télécharger

👉 **[Dernière version](https://github.com/inkimat/copicol-telechargement/releases/latest)**

Aucune installation : téléchargez le fichier `.exe` et lancez-le, depuis le
disque ou une clé USB. Windows 10 ou 11, sans droits d'administrateur.

## Version de démonstration

La démo fonctionne **en simulation** : elle parcourt vos dossiers et produit
le rapport complet (fichiers à renommer, nom avant / après, erreurs), sans
rien copier. La copie, la reprise et la restauration demandent une licence :
[plan-code.lemonsqueezy.com](https://plan-code.lemonsqueezy.com).
